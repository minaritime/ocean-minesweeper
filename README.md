# 세계지도 지뢰찾기

세계지도의 바다에서만 지뢰를 찾는 지뢰찾기입니다. 매판 지구가 무작위로 돌아가고 격자가 어긋나서 바다 모양과 지뢰 위치가 달라집니다.

플레이: https://minaritime.github.io/ocean-minesweeper/

- 시작 화면에서 모드(**기본** / **능력**)와 난이도를 고르고 시작. 하던 판이 있으면 시작 버튼 아래 이어하기 팻말이 걸림
- 능력 모드: 첫 칸을 연 뒤, 찾아낸 바다 33%, 66%에 능력을 하나씩 받음 (4개 중 무작위 3개를 보고 하나 고르기, 고르는 동안 시간 멈춤). 같은 능력을 또 고르면 횟수가 더해짐
  - 🔍 탐지 ×3: 고른 칸이 지뢰면 깃발, 아니면 열기
  - 👁️ 투시 ×1: 고른 칸 주변 3×3을 한 번에 풀기
  - 🔦 등대 ×2: 보이는 화면에서 숫자 0인 칸 하나 열기 (없으면 숫자가 가장 작은 칸)
  - 🛡️ 방패 ×1: 가지고 있으면 지뢰를 한 번 밟아도 버팀 (자동)
  - 능력 칸 클릭 또는 숫자키 1~4, 대상 고르기는 오른쪽 클릭이나 Esc로 취소
  - 능력 종류·횟수는 `js/abilities.js` 의 `ABILITIES` 표만 고치면 바뀜
- 난이도 4단계: 쉬움 300열 · 보통 450열 · 어려움 600열 · 최고 800열 (최고는 바다 약 19만 칸, 지뢰 약 2만 8천 개)
- 바다는 모두 한 덩어리로 이어져 있음: 지도 데이터에서 막힌 실제 해협(지브롤터, 다르다넬스·보스포루스, 케르치, 바브엘만데브, 호르무즈, 덴마크 해협)을 뚫고, 그래도 떨어진 조각은 육지로 바꿈
- 왼쪽 클릭: 열기 / 오른쪽 클릭: 깃발 / 숫자 칸 클릭: 주변 한꺼번에 열기
- 칸이 아주 작게 보일 때 누르면 그 자리를 먼저 확대
- 휴대폰: 탭 열기, 길게 눌러 깃발 (⛏ 버튼으로 탭 동작 바꾸기), 두 손가락으로 확대축소
- 휠로 확대축소, 끌어서 이동 (지도는 동서로 이어짐)
- 이어하기: 진행 중인 판을 자동 저장. 다시 열면 시작 화면의 이어하기 팻말로 이어 감 (판 하나, 이 기기 브라우저에 저장, 끄고 있던 시간은 안 셈, 능력 모드는 가진 능력까지 저장)
- 📜 클리어 기록: 모드·난이도별 최고 기록·클리어·도전 횟수, 빠른 순/최근 순 목록 (이 기기 브라우저에 저장)
- 🔄 또는 R: 시작 화면 (하던 판은 멈춤, Esc나 팻말로 돌아감), F: 깃발 모드, H: 기록, 0: 전체 보기

지도 데이터: Natural Earth (world-atlas 110m, 퍼블릭 도메인)

테스트: `npm test`
