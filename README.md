# 바다 지뢰찾기

세계지도 위 바다에서만 지뢰를 찾는 지뢰찾기입니다. 매판 지도가 돌아가고 격자가 어긋나서 바다 모양과 지뢰 위치가 달라집니다.

플레이: https://minaritime.github.io/ocean-minesweeper/

- 왼쪽 클릭: 열기 / 오른쪽 클릭: 깃발 / 숫자 칸 클릭: 주변 한꺼번에 열기
- 휴대폰: 탭 열기, 길게 눌러 깃발 (⛏ 버튼으로 탭 동작 바꾸기)
- 휠·두 손가락으로 확대축소, 끌어서 이동 (지도는 동서로 이어짐)
- 난이도 4단계: 쉬움 80열 · 보통 120열 · 어려움 160열 · 최고 200열 (최고는 바다 약 1만 2천 칸)
- 📜 클리어 기록: 난이도별 최고 기록·클리어·도전 횟수, 빠른 순/최근 순 목록 (이 기기 브라우저에 저장)
- R: 새 판, F: 깃발 모드, H: 기록, 0: 전체 보기

지도 데이터: Natural Earth (world-atlas 110m, 퍼블릭 도메인)

테스트: `npm test`
